# Evyni

**A companion agent that evolves with you.**

Evyni is an early-stage project exploring open architectures for long-term companion agents: agents designed around continuity, memory, initiative, boundaries, and user ownership.

This repository is intentionally minimal for now. The architecture, implementation scope, upstream attribution, and open-source license will be documented before the first code release.

## Status

Repository reserved. Design in progress.

No framework code, private persona data, credentials, memories, or user content has been published.
